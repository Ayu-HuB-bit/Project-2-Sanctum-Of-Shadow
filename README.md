# Project-2-Sanctum-Of-Shadow

Sanctum of Shadows - Systems Design Document & Visual Research Case Study

## 📋 Project Overview
Sanctum of Shadows is a detailed design and mechanics case study split into two distinct parts: a comprehensive 34-page Systems Design Document mapping out core mechanics, and a Visual Research Dossier establishing the project's artistic direction. 

The main objective of this project was to design a balanced game system featuring asymmetric hidden roles and a modular, shifting board layout, while conducting user research to craft a unified visual theme.

---

## 🔬 Systems Design & Visual UX Principles Applied
The structural rules and visual assets for Sanctum of Shadows were built and evaluated using human-computer interaction (HCI) and standard game design principles:

### 1. Asymmetric Gameplay Loops & Shifting Board Logic
To ensure fair and balanced mechanics across competing player roles with entirely different rules, the system logic was thoroughly mapped:
* **Hidden-Role Asymmetry:** Designed and balanced separate control rules for opposing players, verifying state changes to ensure gameplay remains competitive and fair for both sides.
* **Modular Spatial Layout:** Structured a shifting tile board system, requiring precise tracking of player movement paths, boundaries, and changing coordinate states.
* **Resource and Cooldown Tracking:** Programmed specific tactical resource curves (action cooldowns, tactical meters, visibility points) to make sure game progression relies entirely on strategic user choice.

### 2. Visual Theme Research & Aesthetic Design
The second phase of the project focuses on establishing the interface look, color psychology, and character silhouettes to support the gameplay mood:
* **Thematic Mood Boarding:** Gathered and evaluated visual references to craft a dark, high-tension atmosphere, focusing specifically on a black and purple color palette and menacing shogun-ninja armor silhouettes.
* **Interface Clarity and Visibility:** Styled user interface concepts and character assets to ensure high contrast, making sure that dark shadow themes enhance the visual hierarchy rather than cluttering active game screens.
* **Matching Rules with Visuals:** Aligned the psychological tension of the game mechanics directly with the visual art style, ensuring the gameplay rules and the dark aesthetic work in harmony to create an immersive user experience.

---

## 🛠️ Documentation & Project Lifecycle
The completion of this design case study followed standard technical writing and project verification steps:
* **System Specification Writing:** Authored a 34-page game design document outlining complete rule sets, win conditions, and mechanical balance curves.
* **Visual Asset Selection:** Cross-referenced historical and cultural design references with user interface layouts to guarantee clear target visibility during active play states.
* **Rule Matrix Testing:** Simulated  player movements and turn actions through structural matrices to verify that the game rules stay mathematically unbroken across all character combinations.
